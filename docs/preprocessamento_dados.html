Por que não trocar o interpolador?

INTER_NEAREST não é a escolha usual para fotografias, mas é parte da construção do artefato curado. Trocá-lo mudaria os pixels, invalidando a partição congelada e a comparabilidade com resultados já produzidos.

Travas de integridade

Sem duplicidade de posse

Uma imagem não pode aparecer mais de uma vez no mesmo dataset × fold × tarefa.

Sem vazamento de lesão

Fotos do mesmo lesion_id não podem atravessar clientes ou train/val/test.

Partição congelada

Treino federado e local-only leem exatamente o mesmo CSV mestre; ele não é recriado silenciosamente.

Caminhos não são editados

Mover dados invalida os caminhos relativos. A correção é regenerar de forma determinística, nunca editar o CSV à mão.

05 · Tratamento em tempo de treino

O arquivo vira tensor sob demanda

O dataset é lazy: guarda apenas as linhas do CSV e abre cada imagem no __getitem__. Isso evita manter milhares de imagens na memória e permite que cada cliente carregue apenas a própria fatia.

C×H×W

Imagem

BUSI: tensor float32 1×128×128. ISIC: OpenCV BGR → RGB, transposição e tensor 3×128×128.

0/1

Máscara

A máscara é lida em cinza, converte 255 para 1 e ganha dimensão de canal: 1×128×128.

−1

Supervisão ausente

Segmentação-only recebe label −1; classificação-only recebe máscara zerada. O trainer usa apenas a supervisão da tarefa do cliente.

O que muda entre train, validation e test

Train

  • pode aplicar oversampling determinístico;
  • shuffle em modo epochs;
  • flip horizontal p = 0,5;
  • flip vertical p = 0,5;
  • rotação aleatória até 360°;
  • batch size configurado (32).

Validation

  • sem oversampling;
  • sem transformações geométricas;
  • sem shuffle;
  • batch size configurado;
  • usada para avaliação local/diagnóstico.

Test

  • sem oversampling;
  • sem transformações geométricas;
  • sem shuffle;
  • batch size = 1;
  • reservado para a avaliação final.
Imagem e máscara se movem juntas

Antes das transformações geométricas, a máscara, os canais da imagem e eventuais canais derivados são concatenados. Assim, um único sorteio de flip/rotação é aplicado a todos; depois o tensor é separado novamente. Isso mantém o contorno alinhado à lesão.

06 · Reprodução

Como gerar os artefatos

O dataset selecionado em src/config.yaml deve corresponder ao script. A partição federada é criada somente quando existe intenção explícita de gerar ou substituir esse artefato experimental.

# 1) Em src/config.yaml, selecione data.dataset e uma variante coerente.

# 2) Gere o contrato físico de cada dataset (execute um por vez).
python -m src.dataset.Curated_BUSI_preprocessing
python -m src.dataset.ISIC_2018_preprocessing

# 3) Com os dois mapping.csv prontos, gere a partição multi-dataset.
python -m src.dataset.federated_partition

# Saída consumida pelo estudo:
data/federated_multi/federated_mapping.csv
Resumo operacional

Pré-processar altera os arquivos da variante. Particionar não altera imagens: cria atribuições no CSV. Treinar não altera nenhum dos dois: carrega a fatia e aplica transformações apenas em memória.
